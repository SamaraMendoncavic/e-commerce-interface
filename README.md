# Sensly — homepage demonstrativa

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador. Para desenvolvimento, também pode usar a extensão Live Server do VS Code.

## Recursos
- Layout responsivo inspirado no protótipo fornecido.
- Busca e filtro de produtos por nome/categoria.
- Detalhes dos produtos em janela acessível.
- Carrinho demonstrativo com quantidades e total.
- Link para pular ao conteúdo, foco visível, textos alternativos e suporte a movimento reduzido.

## Observações
- As fotografias são carregadas de URLs externas do Unsplash e precisam de conexão com a internet.
- Preços e carrinho são demonstrativos; não há backend, login real, estoque, checkout ou processamento de pagamento.
- Antes de publicar, valide todas as imagens, os textos alternativos e a acessibilidade com leitores de tela e testes reais.
